\# AutoIt CMD Context Menu Installer



Adds an option to the windows context-menu to open a folder in a command prompt.



\## Features
- Language selection during installation.
- Clean registry management that removes entries when uninstalled.



\## Build locally

1. Compile `src/OpenCmdHere.au3` with \[AutoIt (x64)](https://www.autoitscript.com/site/autoit/downloads/).
2. Open `setup.iss` in \[Inno Setup Compiler](https://jrsoftware.org/isinfo.php).
3. Click \*\*Compile\*\* to compile the setup (Strg + F9) and find the output in `Output/`.
